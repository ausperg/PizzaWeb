# Pizza-Teig-Rechner

Dieses Projekt entstand, weil ich immer wieder manuell mein Lieblingspizza-Rezept hochrechnen musste.
Diese komplett von Hand geschriebene Pizza-Teig-Rechner-Webanwendung (in Zeiten von KI kann man das ja mal betonen) hilft mir, die passenden Mengen für den Pizzateig zu kalkulieren.

 **Erreichbar ist der Pizza-Teig-Rechner unter https://pizza.yellow-cow.de.** <br>
 **Probier ihn gerne aus!**
